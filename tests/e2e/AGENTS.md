# Сквозные тесты

- Проверяй пользовательские сценарии через браузер и наблюдаемые результаты. Компонентные тесты остаются рядом с приложением.
- Используй изолированное тестовое окружение и данные. По возможности выбирай элементы по роли и доступному имени.
- Из корня собери frontend командой `npm --prefix frontend run build`, затем запусти `npm --prefix tests/e2e run test:e2e`.
