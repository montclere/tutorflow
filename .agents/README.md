# .agents

Локальные скиллы Codex, адаптированные из форума. Каждый SKILL.md содержит описание и процедуру целиком.

- [design](skills/design/SKILL.md) — правила и подход перед новой фичей.
- [new-module](skills/new-module/SKILL.md) — новый модуль backend.
- [tdd](skills/tdd/SKILL.md) — правила, тест, реализация.
- [migration](skills/migration/SKILL.md) — схема БД и данные.
- [add-dependency](skills/add-dependency/SKILL.md) — выбор и обновление зависимости.
- [docs-update](skills/docs-update/SKILL.md) — куда писать информацию.

Эксплуатационные скиллы добавляются при появлении инфраструктуры.
