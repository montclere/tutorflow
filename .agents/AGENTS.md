# .agents

Правила локальных скиллов; действуют также [общие правила](../AGENTS.md).

- Держи каждый скилл в `skills/<имя>/SKILL.md` с полями name и description.
- Храни шаги в `docs/skills/`; в SKILL.md оставляй относительную ссылку на процедуру.
- При переносе из другого проекта адаптируй пути и ограничения, не переноси секреты и продуктовые требования.
