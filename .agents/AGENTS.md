# Процедуры агента

- В [skills](skills/) находятся проектные процедуры. Выбирай скилл по описанию и текущей задаче.
- Открывай только выбранный SKILL.md и явно необходимые ресурсы. Учитывай границы поручения и уже данное разрешение.
- Скилл содержит вход, порядок действий и результат. Используй общие правила из корня и локальные правила выбранной области.
- Команды ищи в справке [утилит](../scripts/). Повторяемые действия выполняй существующими режимами.
- Расширяй подходящий скилл при уточнении его процесса. Новый скилл нужен для самостоятельного повторяющегося процесса.
- Пути к изменяемым реализациям и перечни возможностей определяй по локальным AGENTS.md и справке инструментов.
