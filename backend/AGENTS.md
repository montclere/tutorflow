# backend

Правила серверной части; действуют также [общие правила](../AGENTS.md).

- Выбери и запиши стек в [decisions](../docs/decisions.md) до установки зависимостей.
- Держи простое хранение данных простым модулем; вводи domain/application/infrastructure/presentation при появлении бизнес-правил.
- Проверяй права и входные данные на сервере для каждого объекта.
- Вызывай БД и внешние сервисы через границы, позволяющие тестировать бизнес-правила без сети.
- Меняй схему БД миграциями; не редактируй уже применённые миграции.
- Меняй [контракт API](../docs/frontend-api.md) вместе с API; согласуй несовместимость с владельцем frontend.
- Вместе с первым кодом добавь `backend/scripts/check.sh`: линт, типы и тесты выбранного стека.
