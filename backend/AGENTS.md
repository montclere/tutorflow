# Backend

- Начинай с правила в `docs/business-rules.md` и критериев задачи. Бизнес-логику держи вне HTTP-обработчиков, запросов к БД и схем ответов.
- Добавляй доменный модуль, когда появляется реальный сценарий. Между модулями используй `public`-контракты. Каждый модуль владеет своими данными.
- Проверяй права на объект на сервере. Изоляцию преподавателей, отказы и повторные запросы покрывай тестами на подходящей границе.
- Backend-тесты храни в `backend/tests/`. Связывай их с BR через pytest-маркеры и `rule-map.json`. Из корня запускай `python3 scripts/check.py rule BR-…` и `python3 scripts/check.py pr`.
