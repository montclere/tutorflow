# frontend

Браузерный интерфейс TutorFlow на TypeScript и CSS. Сценарии включают вход, регистрацию, личный профиль и кабинеты репетитора, ученика и родителя. API вызывается с того же origin через Caddy. Секрет приглашения переносится во фрагменте адреса.
