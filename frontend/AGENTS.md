# Frontend

- Вход задачи — выбранный UC, BR и HTTP-контракт OpenAPI. Требования найди через [документацию](../docs/).
- Прочитай затронутый экран, его сетевые вызовы, состояния и ближайшие тесты. Открывай backend по конкретному изменяемому контракту.
- Держи сетевые вызовы в одном месте. Показывай подтверждённый результат, загрузку, пустое состояние и отказ сервера.
- Проверяй клавиатуру, узкий экран и сохранение независимых изменений.
- Компонентные проверки храни рядом с кодом. Сквозные сценарии находятся в [тестах](../tests/e2e/).
- Используй настроенные форматтер, линтер и проверки типов через [утилиты](../scripts/). Точные версии и команды определяй по манифесту и справке.
