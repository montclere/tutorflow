# frontend

Правила интерфейса; действуют также [общие правила](../AGENTS.md).

- Стек — [INF-7](../docs/adr/platform.md#inf-7--стек-веб-интерфейса); новые зависимости — по скиллу `add-dependency`.
- Кабинет строй из компонентов `src/shared/ui/kit` (shadcn/ui) и иконок `lucide-react`; эмодзи не используй.
- Цвета, шрифты, кегли и радиусы бери только из `src/styles/tokens.css`; тексты — из `src/content/*.ru.ts`, название и цены — из `src/config/site.ts`.
- Логику держи в `model`-модулях с тестами, разметку — в компонентах.
- Бери поведение из [ADR интерфейса](../docs/adr/web.md) и [ADR модулей](../docs/adr/README.md), API — из [контракта](../docs/api/README.md).
- Держи обращения к API в одном слое; явно отделяй тестовые данные от рабочего подключения.
- Не показывай успех до подтверждения сервера; обрабатывай загрузку, пустой результат и ошибки.
- Проверяй клавиатурную навигацию и узкий экран; клиентские проверки прав дополняют серверные.
- Перед сдачей запускай `npm run lint`, `npm run typecheck`, `npm test`, `npm run build`; браузерные сценарии — в `./scripts/dev.sh check`.
