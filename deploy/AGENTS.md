# Развёртывание

- Здесь находятся конфигурация окружения, мониторинг и служебные команды развёртывания.
- Прочитай только изменяемую конфигурацию, её примеры параметров и необходимые проверки. Работу с целевым окружением выполняй в пределах явного поручения.
- Секреты поступают из окружения. Примеры содержат безопасные значения и назначение параметров.
- Локальные сервисы, предназначенные для разработки, слушают loopback.
- Проверяй конфигурацию и правила оповещений штатными командами из локальных [scripts](scripts/). Общий запуск доступен через [утилиты проекта](../scripts/).
- Для рабочего обновления определи готовность, совместимость, восстановление данных и откат. Изменяемые значения ищи в конфигурации.
