# deploy

Правила развёртывания; действуют также [общие правила](../AGENTS.md).

- До настройки выбери способ запуска и окружения в [ADR платформы](../docs/adr/platform.md).
- Храни только примеры конфигурации; секреты и реальные адреса доступа не коммить.
- Проверяй обязательные переменные при старте; не подставляй небезопасные значения по умолчанию.
- Фиксируй версию выпуска; не публикуй БД наружу.
- Описывай выкатку, проверку здоровья, резервирование и откат вместе с конфигурацией.
- Добавь `deploy/scripts/check.sh` вместе с первой рабочей конфигурацией.
- Выполняй выпуск и действия на сервере только в рамках явного поручения; до этого подготовь проверку здоровья, резервирование и откат.
