# Deploy

- Храни Compose, примеры окружения и утилиты развёртывания в `deploy/`. Пример `.env.example` содержит только безопасные значения для настройки.
- PostgreSQL для разработки слушает loopback. Работу с реальными окружениями выполняй в рамках явно поставленной задачи.
- Описывай назначение переменных рядом с примером окружения в `deploy/.env.example`. Для проверки конфигурации запускай `sh deploy/scripts/check.sh`.
