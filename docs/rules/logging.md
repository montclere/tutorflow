# logging

Правила журналирования; реализация и библиотека пока не выбраны.

- Пиши событие, результат, время и идентификатор запроса; формат выбирается вместе со стеком.
- Не пиши пароли, токены, cookie, тела запросов, почту и другие персональные данные.
- Логируй сбой на границе обработки один раз; связывай внутреннюю диагностику с безопасным кодом ошибки клиента.
- Отдельно фиксируй административные изменения: исполнитель, действие, объект, результат; не секретное содержимое.
- Каталог событий добавлять вместе с первым модулем; выдуманных работающих событий пока нет.
