# UC-010 — Взрослый управляет детским входом

- Акторы: взрослый, ребёнок.
- Цель: предоставить ребёнку собственный вход с отдельно определёнными полномочиями взрослого.
- Предусловие: модель полномочий и подтверждения управления согласована до реализации.
- Основной поток: подлежит согласованию; создание, восстановление и передача управления входом ребёнка не реализуются через UC-003.
- Варианты: у ребёнка уже есть аккаунт; несколько взрослых; отзыв доступа взрослого; восстановление входа; передача управления.
- Результат: учебная идентичность ребёнка сохраняется независимо от аккаунта взрослого и карточек преподавателей.
- Требования: BR-019, BR-020.
- Гипотеза ценности: ребёнок получает собственный доступ без потери идентичности при изменении полномочий взрослых.
- Статус: Д — выделен владельцем в отдельный сценарий; продуктовая модель пока не утверждена.

## Открытые вопросы

До кода определить подтверждение полномочий взрослого, допустимые действия с существующим аккаунтом, способы входа ребёнка, восстановление, конфликт нескольких управляющих взрослых и передачу управления. Подключение взрослого к карточке само по себе не даёт эти полномочия. Требуется отдельно определить необходимые согласия и применимые ограничения целевого запуска.
