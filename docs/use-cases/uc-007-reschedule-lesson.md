# UC-007 — Участники переносят или отменяют занятие

- Акторы: преподаватель; ученик или взрослый с правом управления расписанием.
- Цель: участники переносят или отменяют занятие.
- Основной поток: действия через API с проверкой прав, версий и сохранением истории.
- Варианты: исправления, повторные запросы, отказ в доступе и конкурирующие изменения проверяются в соответствующем сценарии.
- Результат: Преподаватель меняет время будущего занятия, отменяет и восстанавливает его с проверкой версии и предупреждением о пересечениях.
- Требования: BR-044–BR-048, BR-052.
- Гипотеза ценности: меньше ручного согласования и понятное актуальное расписание.
- Статус: С; согласован простой API для MVP.

## Критерии приёмки

- Преподаватель меняет время будущего занятия, отменяет и восстанавливает его с проверкой версии и предупреждением о пересечениях.
- Текущий ответственный за расписание запрашивает перенос или отмену индивидуального занятия; для группового занятия доступен только запрос отмены собственного участия.
- Причина необязательна; предложенное время допустимо только для переноса. Один открытый запрос на участие; автор отзывает его, преподаватель принимает либо отклоняет.
- Изменение содержания занятия делает старые запросы неактуальными. Принятие проверяет исходную версию, текущее право и будущую дату; откат не оставляет частичного результата.
- Отмена участия сохраняет ученика в снимке с отдельной отметкой, не отменяя группу. Участник не переносит всю группу и не создаёт автоматически отдельный урок.
- Отмена сохраняется в календаре и истории, отличается от удаления и освобождает занятое время. Восстановление будущего занятия не возрождает прежнее согласование.
- Отдельное изменение серии сохраняется как исключение. Период будущей серии управляется существующими паузами и возобновлением UC-006.

## Границы

- Только API расписания. BR-049–BR-051 остаются будущими интеграциями уведомлений и финансов; начисления и отправка сообщений не реализуются.
- Запрос не резервирует предложенное время. После принятия перенос предупреждает о пересечениях, но не запрещается.
