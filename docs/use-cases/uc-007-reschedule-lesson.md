# UC-007 — Участники переносят или отменяют занятие

- Акторы: преподаватель; ученик или взрослый с правом управлять записью.
- Цель: изменить встречу без потери связанных данных.
- Основной поток: 1) преподаватель редактирует урок либо перетаскивает его; или участник отправляет запрос; 2) система предупреждает о конфликтах; 3) после принятого изменения обновляет план, историю, будущие напоминания и передаёт факты для финансового учёта.
- Варианты: отмена с полным, частичным, нулевым начислением или ручным решением; изменение группы целиком или отдельного участия; несколько переносов через обычное перемещение событий вместо специальной команды «обмен».
- Результат: понятное актуальное расписание с историей и обновлёнными связанными последствиями.
- Требования: BR-044–BR-052.
- Гипотеза ценности: одно изменение — согласованное обновление связанных процессов.
- Статус: С; финансовые формулы и блокировка предлагаемых слотов — Д.
