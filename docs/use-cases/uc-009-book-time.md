# UC-009 — Преподаватель открывает время для записи

- Акторы: преподаватель; ученик или взрослый с правом управления расписанием.
- Цель: преподаватель открывает время для записи.
- Основной поток: действия через API с проверкой прав, версий и сохранением истории.
- Варианты: исправления, повторные запросы, отказ в доступе и конкурирующие изменения проверяются в соответствующем сценарии.
- Результат: Преподаватель публикует разовые либо регулярные свободные интервалы для индивидуальной записи; существующие личные блоки означают занятость, например обед или перерыв.
- Требования: BR-062–BR-070.
- Гипотеза ценности: меньше ручного согласования и понятное актуальное расписание.
- Статус: С; согласован простой API для MVP.

## Критерии приёмки

- Преподаватель публикует разовые либо регулярные свободные интервалы для индивидуальной записи; существующие личные блоки означают занятость, например обед или перерыв.
- Публикация задаёт одну длительность, шаг начала, перерыв, цену в RUB и мгновенный режим либо подтверждение. Видимость: все свои подключённые карточки, выбранные карточки либо участники выбранных групп.
- Только текущий ответственный карточки записывает ученика. Наблюдатель читает доступность без права записи. Чужое расписание и причины занятости не раскрываются.
- Уроки, блоки занятости и действующие резервы исключают соответствующую часть интервала с перерывами. Остаток доступен; одновременные попытки не создают двойной записи.
- Простой режим подтверждения: один резерв на выбранное время и один ожидающий запрос на карточку у преподавателя. Срок настраивается, по умолчанию 24 часа и не позднее начала. Отказ, отзыв и истечение освобождают слот.
- Подтверждение создаёт обычное занятие со снимком цены; проверяет актуальные условия и доступность. Изменение ответственного сохраняет запрос, управлять им может текущий ответственный.
- Преподаватель предлагает несколько альтернатив для одного индивидуального занятия. Выбор одного повторно проверяет время и закрывает остальные; сами альтернативы не резервируют время.
- Ученик либо ответственный взрослый публикует удобные часы и исключения недоступности. Преподавателю доступны только итоговые свободные интервалы без причин; пересечение интервалов является подсказкой, не назначением.

## Границы

- Только API и самый простой поток индивидуальной записи. Конкурирующие заявки на один резерв, групповая запись и сложные политики очереди отложены.
