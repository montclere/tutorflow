# UC-009 — Преподаватель открывает время для записи

- Акторы: преподаватель, ученик, взрослый с правом управления записью.
- Цель: согласовать урок через доступные интервалы без переписки.
- Основной поток: 1) преподаватель выделяет интервал календаря либо задаёт регулярную доступность; 2) указывает аудиторию и режим — немедленная запись либо запрос; 3) ученик/уполномоченный взрослый выбирает время; 4) система фиксирует запись или резервирует время для решения преподавателя; 5) доступность оставшегося интервала пересчитывается.
- Варианты: предложение нескольких вариантов с выбором одного; ученик указывает собственную доступность или недоступность; система подсказывает пересечения интервалов, не назначая занятие сама; интервалы допускают несколько последовательных занятий с настраиваемыми перерывами.
- Результат: запись или запрос на запись, опубликованная доступность актуализирована.
- Требования: BR-062–BR-070.
- Гипотеза ценности: самостоятельная запись при контроле преподавателя и без удаления длинного доступного интервала целиком.
- Статус: С; точный алгоритм резерва, продолжительности и конфликта — Д.
