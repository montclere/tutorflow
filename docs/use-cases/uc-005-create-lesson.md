# UC-005 — Преподаватель создаёт и согласовывает занятие

- Акторы: преподаватель; по необходимости ученик или уполномоченный взрослый.
- Цель: быстро назначить индивидуальное или групповое занятие.
- Основной поток: 1) преподаватель нажимает интервал календаря или «Создать занятие»; 2) выбирает участника/группу, дату и продолжительность; 3) система предлагает значения по умолчанию; 4) преподаватель создаёт занятие непосредственно или отправляет предложение; 5) событие отражается в доступных участникам календарях.
- Варианты: несколько учеников без постоянной группы; незарегистрированный ученик; подтверждение/отклонение предложения; предупреждение о пересечении без раскрытия чужих данных; личная занятость — календарный блок, не урок.
- Результат: сохранённое занятие или предложение со статусом.
- Требования: BR-028–BR-036.
- Гипотеза ценности: минимум шагов и согласование времени внутри платформы.
- Статус: С — API и основные правила уточнены владельцем; назначение единственного ответственного также согласовано.

## Согласованные границы API

Индивидуальное занятие содержит минимум одну собственную карточку ученика; также можно выбрать несколько карточек или группу. Пустая группа может иметь заранее запланированные занятия без участников. Архивные ученики и архивные группы для нового назначения недоступны. Начало и длительность обязательны; название, предмет, формат и заметки необязательны. Подключённый аккаунт ученика не требуется.

Учебный профиль — набор предметных настроек и цены в карточке, а не отдельная личность ученика. Урок можно создать без выбранного профиля, указав стоимость явно либо применив сохранённую настройку преподавателя. Цена означает сумму за занятие, автоматического почасового пересчёта нет. У участников группы могут быть разные цены.

При создании в занятии фиксируются участники и их цены. Последующее изменение группы, её стоимости и учебных профилей не меняет сохранённое занятие. Преподаватель может явно переопределить условия конкретного будущего занятия. Начисления, оплата, новые экраны, уведомления и связанные материалы в этот поток не входят.

Назначение сохраняет занятие сразу. Режим согласования отдельно собирает ответы участников: отказ одного не удаляет остальных и не превращает групповое занятие в отказанное целиком. Для ученика без подключённого аккаунта преподаватель составляет собственное расписание без фиктивного электронного ответа.

Для одного ученика ответственный за согласование только один: сам ученик либо выбранный взрослый с явным полномочием. Остальные взрослые сохраняют доступ наблюдателя. Первоначальный ответственный назначается при первом подключении ученика либо взрослого, если ответственного ещё нет. Последующее подключение не перехватывает полномочие. Преподаватель может явно переназначить его; одно полномочие принадлежит не более чем одному подключённому аккаунту. При отключении ответственного его полномочие прекращается; при отсутствии других подключений согласование не требуется. Правила других категорий полномочий появятся вместе с их действующими модулями.

Конкретное занятие хранит точный момент начала в UTC и часовой пояс исходного планирования. Участникам показывается время в выбранном ими часовом поясе; изменение профиля не сдвигает событие. Пересечения не запрещают сохранение. Собственные уроки и личная занятость преподавателя дают предупреждение; события ученика у других преподавателей автоматически не раскрываются даже как занятость. Его явная доступность относится к UC-009. Соседние интервалы с совпадением конца и начала не пересекаются.

Прошедшие и начавшиеся уроки не переписываются операциями редактирования будущего расписания. Изменения будущих событий сохраняют историю инициатора и существенных значений. Запросы ученика на перенос, финансовые последствия отмен и факт проведения относятся к UC-007–UC-008.
