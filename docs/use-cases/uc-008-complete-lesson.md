# UC-008 — Преподаватель проводит и завершает занятие

- Акторы: преподаватель; ученик или взрослый с правом управления расписанием.
- Цель: преподаватель проводит и завершает занятие.
- Основной поток: действия через API с проверкой прав, версий и сохранением истории.
- Варианты: исправления, повторные запросы, отказ в доступе и конкурирующие изменения проверяются в соответствующем сценарии.
- Результат: Преподаватель после начала занятия вручную фиксирует проведено либо не проведено; до отметки результат неизвестен.
- Требования: BR-053–BR-057, BR-061.
- Гипотеза ценности: меньше ручного согласования и понятное актуальное расписание.
- Статус: С; согласован простой API для MVP.

## Критерии приёмки

- Преподаватель после начала занятия вручную фиксирует проведено либо не проведено; до отметки результат неизвестен.
- Посещаемость каждого участника отдельная: присутствовал, отсутствовал, не отмечено. Согласование и отмена не заменяют факт проведения.
- Отметки и необязательная личная заметка исправляются с проверкой версии и неизменяемой историей инициаторов.
- API выдаёт ограниченный список закончившихся по времени занятий без результата. Время окончания само по себе не подтверждает проведение.
- Участник видит собственную посещаемость и общий результат, без чужих отметок и личной заметки преподавателя.
- Ученик и взрослый не выставляют факт участия. Опоздание и фактическая длительность отложены.

## Границы

- Только API. Автоматическое проведение, начисления, ДЗ, отчёты, уведомления и BR-058–BR-060 не входят в этот поток.
