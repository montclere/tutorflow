# Этапы TutorFlow

## Bootstrap

- Объём: распаковать стартовый комплект в новом `dev`, подключить API, web, локальную БД, проверки и CI.
- Затронуты общие файлы: README, настройки GitHub и hooks, скрипты проверок и карта тестов.
- Продуктовые BR-ID в этом этапе не реализуются. Готовность определяют запуск приложений, smoke-тесты и отказ адресной проверки при отсутствии тестов BR.

Локально подготовлены HTTP health endpoint, стартовая страница, Compose для PostgreSQL и workflow `verify`. Frontend и браузерные тесты устанавливают зависимости из собственных lockfile. Карта BR-тестов пуста до реализации первого правила. Локальные проверки прошли. Публикация bootstrap, первая очередь Issues и проверка GitHub CI по SHA ожидают указания приватного репозитория.

[Материалы стартового архива](bootstrap/place-files.md).

## Первый пользовательский сценарий

1. Рабочее пространство после регистрации преподавателя (BR-001, UC-001). Перед реализацией согласовать требования к регистрации и проверке личности.
2. Карточка ученика без аккаунта (BR-005, UC-002). После регистрации проверить права преподавателя и изоляцию карточек.
3. Индивидуальный урок ученику без аккаунта (BR-029, UC-005). После карточки согласовать обязательные поля урока и начальный статус.
