# Статус TutorFlow

- Backend и браузерный интерфейс работают для регистрации, входа, профиля, кабинетов, приглашений, создания карточек и отзыва доступа. Правила и границы указаны в [ADR](adr/README.md).
- Проверки запускаются локально на отдельном стеке с PostgreSQL и Chromium. Workflow GitHub Actions удалён из рабочей ветки. Ревью второго участника проводится до интеграции.
- Завершены [доставка кодов, восстановление и приватность](tasks/identity-delivery.md) и [согласование HTTP-ответов](tasks/http-contract.md).
- Занятия и расписание реализованы локально. Доступны разовые и еженедельные уроки, история, посещаемость, переносы по согласию и подключение родителя к существующей карточке. Перед интеграцией требуется независимое ревью. [ADR Lessons](adr/lessons.md) · [Задача](tasks/lessons-schedule.md)
- Перед публичным запуском владелец закрывает [предрелизный список](pre-release.md).
