# decisions

Решения, причины и открытые вопросы.

## INF-1 — устройство репозитория

- Дата: 2026-11-16. Статус: принято в рамках настройки репозитория.
- Папки: backend, frontend, docs, deploy, scripts; скиллы в `.agents/skills`.
- Основа: workflow соседней `forum-nstu-beta`, без её кода, секретов и требований.
- Работа двух участников: отдельные ветки/worktree, задачи от dev, ревью вторым участником, выпуск из main.
- Стек приложения и окружения пока не выбраны.
- Локальная CLI-команда и GitHub Actions запускают одинаковые проверки; настройки Claude не используются.
- CI запускается на push в main и PR в dev. Код или конфигурация модуля без его скрипта проверок блокирует проверку.
