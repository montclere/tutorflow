# Вёрстка: лендинг с регистрацией и кабинеты

**Этап: только интерфейс.** Лендинг, кабинеты репетитора и ученика как настоящее приложение: компоненты, маршруты, переходы. **Бизнес-логику не делаем:** никаких API, базы данных, авторизации, платежей, ИИ, отправки писем. Все данные — моки.

## 1. Маршруты

| Путь | Экран |
|---|---|
| `/` | Лендинг с регистрацией |
| `/teacher` | Репетитор → Обзор |
| `/teacher/schedule` | Расписание; вид и дата в адресе: `?view=day\|week\|month\|list&date=ГГГГ-ММ-ДД` |
| `/teacher/students` | Ученики |
| `/teacher/tasks` | Задания → «Создать с ИИ» |
| `/teacher/tasks/bank` | Задания → «Банк ЕГЭ и ОГЭ» |
| `/teacher/tasks/mine` | Задания → «Мои задания» |
| `/teacher/review` | Проверка |
| `/teacher/finance` | Финансы |
| `/student` | Ученик → Главная |
| `/student/tasks` | Задания |
| `/student/trainer` | Тренажёр |
| `/student/exam` | Вариант ЕГЭ |
| `/student/progress` | Прогресс |

Вкладки «Банк» и «Мои задания» — отдельные маршруты. Вкладки внутри ученических «Заданий» — локальное состояние.

## 2. Переходы между экранами

```
Лендинг /
 ├─ «Создать кабинет бесплатно» → прокрутка к форме регистрации
 ├─ Форма: шаг 1 → (почта → код) → шаг 2 → шаг 3 «Кабинет готов» → «Перейти в кабинет» → /teacher
 ├─ «Смотреть демо» → /teacher (временно, пока нет отдельного демо-адреса)
 ├─ «Войти» (шапка) → прокрутка к форме регистрации
 └─ «Я ученик или родитель» → подсказка + ссылка «Посмотреть кабинет ученика» → /student

Кабинет
 ├─ Логотип → /
 ├─ Переключатель «Репетитор / Ученик» → /teacher или /student
 ├─ Пункты меню → свои маршруты, активный пункт подсвечен
 └─ Ссылки внутри экранов → свои маршруты
```

## 3. Что работает, а что нет

**Работает (локальное состояние):** шаги регистрации и проверки полей; переключение ролей, меню, вкладки; чат ИИ с заготовленным ответом; очередь проверки; тренажёр; вариант ЕГЭ с таймером; переключатель «Сегодня / Завтра» в «Обзоре»; копирование свободных окон; мобильное меню.

**Не работает:** создание урока, ученика, оплаты, экспорт, PDF, отправка задания, импорт, уведомления, поиск. Все такие кнопки вызывают **одну** функцию `notifySoon(label)` и показывают уведомление «… — скоро будет».

## 4. «Обзор» репетитора (`/teacher`)

Ровно четыре элемента сверху вниз. Деньги и финансовые плитки с «Обзора» убраны: суммы живут только в «Финансах».

1. **Шапка.** «Добрый день, {имя}», под ним дата мелким серым. Справа «Задание» (вторичная кнопка) и «Урок» (основная), обе с иконкой «плюс». Другого текста нет.
2. **Ряд 1, около 60/40.**
   - **«Сегодня»:** переключатель «Сегодня · N / Завтра · N», ссылка «Расписание →». Строка урока: время, аватар с инициалами, имя, предмет, бейдж статуса («Проведён», «через 25 мин», «Оплачено», «Долг»), кнопка «Войти». Прошедшие уроки приглушены. Основной кнопкой выделен ближайший непройденный урок.
   - **«Требует внимания»:** счётчик в заголовке, до 5 строк, у каждой одна кнопка: «Отметьте урок» → «Проведён», «N работ на проверку» → «Проверить» (ведёт на `/teacher/review`), «Долг» → «Напомнить», «Пакет заканчивается» → «Продлить», «Не занимается N дней» → «Написать». «Проведён» убирает строку; когда строк нет — «Всё в порядке».
3. **Ряд 2, 50/50.**
   - **«Неделя»:** 7 столбиков Пн–Вс по числу уроков, сегодняшний выделен; в заголовке «N уроков · загрузка P%» (загрузка = уроки / ёмкость недели из моков). Под графиком — свободные окна и кнопка «Поделиться»: копирует окна текстом в буфер обмена. График нарисован простыми элементами, без библиотеки.
   - **«Подготовка к экзаменам»:** ссылка «Все →». Строка: аватар, «Имя · экзамен», «N дней · слабое место №X» или «не занимается N дней», полоса готовности, бейдж «61% ↑» (рост зелёный, падение красное). Если никто из учеников не готовится к экзамену — блок не показывается, «Неделя» занимает всю ширину.
4. На телефоне — одна колонка в том же порядке.

Данные приходят из `getTeacherOverview()`, тексты — из `content/cabinet.ru.ts`.

## 5. «Расписание» репетитора (`/teacher/schedule`)

Вид и дата хранятся в адресе: `?view=week&date=2026-11-17`. По умолчанию «Неделя», на телефоне (до 520 px) — «Список».

1. **Шапка.** Слева заголовок периода («16 — 20 ноября», «Ноябрь 2026», «Вторник, 17 ноября»; по нажатию открывается мини-календарь перехода к дате), стрелки назад / вперёд и кнопка «Сегодня». Справа переключатель вида «День / Неделя / Месяц / Список» и основная кнопка «Урок».
2. **Фильтры.** Выбор ученика с поиском по имени, тип урока (индивидуальный, групповой, пробный), предмет — только если у репетитора в профиле два предмета и больше. Меню «Цвет: по ученикам / по оплате». В «Неделе» — переключатель «Выходные». Справа сводка «N уроков · M свободных окон» за видимый период. Свободные окна считаются по всем урокам, фильтры их не меняют.
3. **Неделя.** Сетка по часам в рабочее время из моков (по умолчанию 12:00–20:00), колонки Пн–Пт, выходные — переключателем. Высота блока урока равна его длительности; внутри имя ученика, время, метка «долг / оплачено / пакет», значок повтора у регулярных уроков. Пересекающиеся уроки делят ширину колонки. Прошедшие уроки приглушены, сегодняшняя колонка выделена, красная линия «сейчас» с точкой. Свободное окно (не короче заданного в моках минимума) — пунктирный блок «свободно»; по нажатию открывается быстрое создание урока (ученик, длительность, повтор; сохранение — `notifySoon`). На телефоне сетка прокручивается по горизонтали внутри контейнера.
4. **День.** Переключатель «Сегодня / Завтра», слева уроки дня с цветной полосой, справа панель ближайшего урока: прошлая тема, домашнее задание, баланс, заметка, «Войти» и «Перенести».
5. **Месяц.** Сетка Пн–Вс: цветные точки уроков и подпись «N уроков», сегодня выделено, выходные темнее. Нажатие на день открывает «День» на эту дату.
6. **Список.** Уроки на ближайшие две недели по дням, с подзаголовками дат.
7. **Карточка урока.** По нажатию на урок в любом виде открывается панель с данными урока и кнопками «Войти», «Перенести», «Отменить», «Проведён» (все через `notifySoon`).
8. **Цвета.** У ученика один цвет (поле `color` в моке, палитра — токены `--cab-tone-*`); он же у аватара во всём кабинете. «По оплате»: оплачено, долг, пакет заканчивается.
9. **Расчёты** — чистые функции с тестами: `model/scheduleLayout.ts` (позиция блока по времени, колонки при пересечении, свободные окна, линия «сейчас»), `model/dates.ts`, `model/scheduleRange.ts`, `model/lessons.ts`.

Демо-данные: репетитор Анна ведёт только математику (ЕГЭ профиль, ЕГЭ база, ОГЭ, алгебра 10 класса). «Обзор» берёт уроки дня, недели и свободные окна из тех же моков расписания.

## 6. Архитектура и дизайн

- **Стек:** Vite + React + TypeScript, CSS Modules и CSS-переменные; в кабинете — компоненты shadcn/ui (Tailwind v4 только слоями `theme` и `utilities`, без сброса стилей, чтобы не трогать лендинг) и иконки `lucide-react`.
- **Токены:** единственный набор цветов, радиусов и шрифтов — `src/styles/tokens.css`. Тема shadcn в `src/styles/tailwind.css` состоит из алиасов на эти токены, своей палитры нет.
- **Визуальный язык:** лендинг яркий (синий фон, огромные заголовки, лайм), кабинет светлый и спокойный. Шрифты Unbounded (заголовки, крупные цифры) и Manrope (текст).
- **Иконки:** только `lucide-react`, один стиль, толщина и размер. Эмодзи в интерфейсе не используются.
- **Каркас кабинета:** боковое меню (из конфига для каждой роли), шапка, область контента.
- **Моки** — `src/cabinet/mocks`, слой `src/cabinet/data/*` возвращает моки; позже его заменят на API.
- **Тексты** — `content/landing.ru.ts`, `cabinet/content/cabinet.ru.ts`. Название, цена, пробный период — в `siteConfig`.
- **Детали:** единая шкала отступов (`--space-*`), одинаковые радиусы и высоты кнопок, `tabular-nums` у чисел, состояния hover / focus / active у всего кликабельного, переходы 150–200 мс, отключённые при `prefers-reduced-motion`, контраст не ниже WCAG AA.

## 7. Адаптив и доступность

- Брейкпоинты: лендинг 1100 / 860 / 560 px, кабинет 1180 / 820 / 520 px. На телефоне меню кабинета выезжает по кнопке.
- Один `h1` на страницу, `nav`, `main`, `section` с заголовками; вкладки — `role="tablist"`; переключатели и чипы — `aria-pressed`.
- Всё доступно с клавиатуры, фокус виден.

## 8. Не делать

API и серверные обработчики, базу данных, авторизацию и сессии, сохранение в `localStorage`, ИИ-вызовы, генерацию PDF, отправку писем и сообщений, платежи, тёмную тему.

## 9. Критерии готовности

- [ ] Все маршруты из раздела 1 открываются, активный пункт меню подсвечен.
- [ ] Путь «лендинг → регистрация → «Перейти в кабинет» → /teacher» работает, как и «Смотреть демо».
- [ ] Логотип в кабинете ведёт на `/`, переключатель ролей — на `/teacher` и `/student`.
- [ ] «Обзор» соответствует разделу 4, «Расписание» — разделу 5 на 1280 и 390 px.
- [ ] Нет хардкода: цвета из токенов, тексты из контента, данные из моков через слой `data`.
- [ ] Все «нерабочие» кнопки вызывают `notifySoon`.
- [ ] Нет сетевых запросов, кроме загрузки шрифтов.
- [ ] Линтер, проверка типов, тесты и сборка проходят.
