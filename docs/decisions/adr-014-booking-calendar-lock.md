# ADR-014 — резерв записи внутри транзакции календаря

- Дата — 2026-11-28.
- Статус — принято.
- Связи — UC-009, BR-064, BR-066, ADR-012, ADR-013.

## Контекст выбора

Самостоятельная запись должна исключать двойное занятие одного времени. При этом преподаватель вправе вручную создавать пересечения. На занятость влияют обычные уроки, ещё не подготовленные экземпляры серии, личные блоки и временные резервы.

## Альтернативы

- Общее exclusion-ограничение по диапазонам PostgreSQL запретило бы разрешённые ручные пересечения и само по себе не проверило бы ещё не подготовленные серии.
- Отдельный сервис резервов потребовал бы согласовывать несколько транзакций и восстанавливать частичные отказы.
- Общая блокировка календаря позволяет проверить все источники и создать урок или резерв в одной транзакции существующего монолита.

## Решение и причины

Запись использует advisory-блокировку календаря преподавателя из ADR-012. До её получения блокируются карточка и необходимые группы. После получения читаются актуальные условия, подготавливаются экземпляры серий в выбранном диапазоне и проверяется занятость. Урок, резерв и история сохраняются общей транзакцией. У публикации, резерва и урока владение связано составными внешними ключами.

Истечение вычисляется по сохранённому сроку, по умолчанию 24 часа и не позже начала занятия. Занятость сразу исключает истёкший резерв; при чтении списка и изменении записи его состояние сохраняется. Отдельный фоновый процесс для правильности записи не требуется.

## Последствия

Записи одного преподавателя сериализуются. Число источников, размер диапазона и вычисления ограничиваются конфигурацией; при превышении API требует сузить запрос. Перерывы сохраняются вместе с записью; перенос и отмена самого урока учитываются по его актуальному состоянию.

## Условия пересмотра

Вернуться к решению при заметном ожидании блокировки одного преподавателя, появлении внешних календарей с отдельным подтверждением либо необходимости очереди нескольких заявок на один слот.
