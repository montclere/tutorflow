# ADR-012 — последовательная запись календаря преподавателя

- Дата — 2026-11-26.
- Статус — принято.
- Связи — UC-005, BR-034, BR-036, BR-097, BR-099.

## Контекст выбора

Пересекающиеся занятия разрешены, но конкурентные операции не должны обе пропускать предупреждение из-за незавершённой записи соседа. Личные блоки и занятия хранятся раздельно, а снимок группы требует согласованного состава.

## Альтернативы

- Запрет пересечений ограничением БД: не соответствует продукту.
- Независимые записи с последующей проверкой: ответ обеих операций может не содержать реального пересечения.
- Общая транзакционная блокировка календаря преподавателя с проверкой после ожидания.

## Решение и причины

Записи занятий и личных блоков используют один PostgreSQL advisory lock на преподавателя. Предупреждения рассчитываются перед завершением транзакции, после получения блокировки. Пересечения проверяются полуоткрытыми интервалами; смежные события допустимы.

Порядок блокировок: карточки по UUID, группа при наличии, календарь преподавателя, изменяемое занятие. Состав группы повторно проверяется под её блокировкой; изменение состава во время подготовки возвращает конфликт с возможностью повторить запрос. Полученные после ожидания ORM-объекты обновляются из БД, а не из identity map.

Ответ ученика блокирует карточку и занятие. Он не меняет время и не захватывает календарь. Версия условий меняется преподавателем; независимые ответы разных участников не инвалидируют друг друга.

## Последствия

Записи одного календаря выполняются последовательно. Блокировка действует только внутри БД и не охватывает доставку сообщений или другие внешние операции. События других преподавателей не запрашиваются для предупреждений: доступность ученика требует отдельного согласованного контракта.

## Условия пересмотра

Измеренная конкуренция записей одного преподавателя или вынесение календаря в отдельное хранилище.
