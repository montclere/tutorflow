# ADR-003 — ограничение вычислений паролей

- Дата — 2026-11-25.
- Статус — принято.
- Связи — UC-001, BR-001, ADR-001, ADR-002.

## Контекст выбора

Перенос Argon2 в asyncio.to_thread освобождает event loop, но сам по себе не ограничивает потребление памяти одновременно исполняемыми вычислениями. Общий пул потоков используется также для логирования и других блокирующих операций. Отмена HTTP-запроса не останавливает уже запущенный поток.

## Альтернативы

- Использовать только общий пул потоков. Его размер не соответствует бюджету памяти Argon2, а очередь может задерживать другие операции.
- Выделить отдельный процесс или сервис вычислений. Это потребует отдельного жизненного цикла, передачи секретных входных значений и обработки отказов между процессами.
- Ограничить допуск к вычислениям в существующем адаптере. Это сохраняет текущую сборку и даёт настраиваемую границу памяти на экземпляр API.

## Решение и причины

Выбран ограниченный допуск к общему пулу потоков с коротким настраиваемым ожиданием. Хеширование и проверка используют один лимит. При исчерпании времени ожидания операция возвращает временную недоступность до запуска нового вычисления.

Внутренняя задача защищена от отмены вызывающего запроса через shield. Адаптер удерживает ссылку на неё и освобождает слот только после её завершения. Иначе отменённые запросы освобождали бы слоты раньше завершения потоков и обходили ограничение памяти.

## Последствия

Лимит действует на экземпляр адаптера, собранный для API. При нескольких процессах общий расход памяти увеличивается пропорционально числу процессов. При перегрузке часть корректных запросов получает временный отказ. Уже запущенное вычисление завершается даже после отмены клиента; оно не удерживает подключение к БД и само не записывает результат.

## Условия пересмотра

Измеряемые задержки общего пула, изменение параметров Argon2, числа workers или бюджета памяти потребуют повторного расчёта лимитов. Отдельный исполнитель понадобится, если ожидание и потребление ресурсов нельзя будет удержать в пределах процесса API.

Причины опираются на описание [потребления памяти Argon2](https://argon2-cffi.readthedocs.io/en/stable/howto.html) и [отмены задач Python](https://docs.python.org/3.12/library/asyncio-task.html#shielding-from-cancellation).
