# Вкладки уроков и заданий ученика

Исполнитель: текущий агент. Ревьюер: владелец проекта. Статус: готово к ревью.

Ветка: `style/student-lessons-tasks`, отдельный worktree со снимком текущего `feat/main-reference`: актуальный frontend и незавершённые правки ещё не интегрированы в `dev` и сохраняются как основа.

Источники: задания владельца, `TutorFlow_Student_Lessons_Reference.png`, `TutorFlow_Student_Tasks_Tab_Reference.png`. Правила: STUDENT-LESSONS-UI-1, STUDENT-TASKS-UI-1, STUDENTS-5/13/15, STUDENT-OVERVIEW-1. Область: только контент двух вкладок и их локальные стили/компоненты. Общие файлы: условия layout в `StudentProfile.tsx`, только тексты уроков/заданий профиля в `cabinet.ru.ts`, `docs/adr/web.md`, `docs/stages.md`. Шапка, строка шести вкладок, остальные вкладки/страницы, модели, хранилища, API и маршруты не меняются.

Критерии: без повторных заголовков; «Уроки» — три KPI, два компактных списка с первыми пятью строками и раскрытием, справа только следующий урок и оплата; «Задания» — четыре KPI, отдельная строка слабых тем/тренажёра и список с реальными фильтрами на всю ширину, без бокового резерва. Данные и расчёты прежние. Сохранены открытие уроков, раскрытие заданий и действия шапки. Есть пустые состояния, фокус и адаптация; синхронное демо-хранилище не подменяется искусственной загрузкой или API.

Реализованы `LessonStat`, `UpcomingLessonList`, `PastLessonList`, `NextLessonCard`, `PaymentSummary`; списки показывают по пять записей с дальнейшим раскрытием. В заданиях сохранены формулы, четыре фильтра, подробности ошибок и существующий переход на проверку. Стили изолированы в `student-tabs.module.css`; на телефоне фильтр перестраивается в два ряда. Модели, данные, API, общие компоненты и остальные страницы сохранены по SHA-256.

Проверки:

- `npm run lint`, `npm run typecheck`, `npm test`, `npm run build` успешны: 299 тестов в 48 файлах. Демо-сборка успешна. Сохраняется предупреждение о JS-чанке больше 500 kB.
- Браузерная проверка ограничения списка сначала падала на исходных 20 строках вместо пяти, после изменения прошла. Google Chrome / Playwright: 1824, 1672, 1440, 1280, 1150, 1024, 821, 768, 620, 430, 390, 375, 320 px; переполнения страницы/модалки и текста фильтров нет. Проверены шесть вкладок, раскрытие пяти следующих записей, открытие ближайшего/будущего/прошедшего урока и возврат, четыре фильтра и реальные ошибки задания, раскрытие Enter и видимый фокус, действия оплаты/задания/материала в шапке. Нет ошибок JavaScript и загрузки ресурсов.
- На Петрове подтверждены прежние 83%, 5/6, долг 1200 ₽ и актуальные даты из демо; на Белове — отсутствие будущих уроков и открытие существующего добавления, на Соколове — отсутствие заданий, слабых тем и тренажёра, на Орловой — переход из ожидающей работы в проверку. Постоянное расписание и платёжные модели не менялись.
- Снимки остальных четырёх вкладок сравнивались до/после на 1672 и 390 px: «Материалы», «Оплаты», «Заметки» совпали побайтно. В «Обзоре» визуально изменений нет; небольшие различия растра backdrop blur (до 16 уровней канала на desktop и один пиксель на mobile) не названы точным совпадением. Исходники этих вкладок и JSX шапки/навигации не менялись.
- `./scripts/dev.sh check` останавливается на существующих ссылках в `docs/tasks/landing-ux.md` и `docs/adr/web.md` на удалённый `UX-REVIEW.md`. Общая интеграционная проверка не завершена; чужое удаление сохранено. Safari/WebKit не проверялся.

Границы: вкладки используют существующее синхронное демо-хранилище, включая его дату `today`; искусственная загрузка, ошибки сети или новые серверные возможности не добавлялись. Исторический урок открывается, если существующее сопоставление находит его в расписании; поведение без такого соответствия сохранено. Числа из PNG не подставляются, поэтому количество строк и значения могут отличаться от референса.
