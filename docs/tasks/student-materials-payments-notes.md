# Материалы, оплаты и заметки ученика

Исполнитель: текущий агент. Ревьюер: владелец проекта. Статус: готово к ревью.

Ветка `style/student-materials-payments-notes`, отдельный worktree со снимком текущего `feat/main-reference`: актуальные незакоммиченные экраны ещё отсутствуют в `dev`, сохранены как основа задачи. Источники — три задания владельца и `TutorFlow_Student_{Materials,Payments,Notes}_Reference.png`.

Границы: контент трёх вкладок и локальные стили, исключение боковой сводки только в них; шапка, шесть вкладок и счётчики сохраняются. Общие файлы: `StudentProfile.tsx`, тексты трёх вкладок в `cabinet.ru.ts`, минимальное расширение существующего демо-хранилища заметок в `data/index.ts`, ADR интерфейса и stages. Модели данных API, backend, авторизация, маршруты, расчёты оплат, остальные страницы и вкладки не меняются. У заметок нет ID и операций изменения/удаления: идентификаторы и адресные операции добавляются только к проекции демо-хранилища, исходные записи не переписываются.

Правила: STUDENT-MATERIALS-UI-1, STUDENT-PAYMENTS-UI-1, STUDENT-NOTES-UI-1, STUDENT-NOTES-2; действующие STUDENTS-6/13/16, STUDENT-OVERVIEW-1. Критерии: три вкладки на всю ширину без бокового резерва; материалы одной поверхностью с реальными файлами/ссылками, статусами и подтверждением удаления; оплаты двумя верхними карточками и одним списком с тремя фильтрами; заметки компактными строками с диалогом добавления/редактирования и подтверждением удаления одной записи. Обновляются списки и счётчики. Даты и существующие расчёты сохраняются, новых фиктивных данных и сетевых состояний нет.

Сделано: локальная тема `profile-records.module.css`, широкие поверхности материалов/заметок, две карточки и единая фильтруемая история оплат, компактный редактор и подтверждение удаления. У заметок новая проекция с ID и адресные операции в существующем хранилище, без изменения исходных фикстур и типов данных сервера. Сохранены просмотренные статусы материалов, безопасное открытие ссылок и скачивание локальных файлов, форма отправки, платёжная форма, абонементы и прежнее действие напоминания.

Проверки:

- `npm run lint`, `npm run typecheck`, `npm test`, `npm run build` успешны: 306 тестов в 50 файлах, включая семь новых. Демо-сборка успешна. Сохраняется предупреждение о JS-чанке больше 500 kB; зависимостей не добавлено.
- Шесть тестов заметок сначала падали на отсутствии ID/изменения/удаления и несортированном списке, затем прошли. Проверены одинаковые записи, стабильные ID, дата, сортировка, границы 0/2000/2001 символов, чужой/неизвестный ID, неизменность исходных заметок и платёжных данных, подписка и повтор удаления. Временное снятие проверки принадлежности заметки ученику ломает тест; код восстановлен, семь тестов модуля повторно зелёные. Отдельный тест истории проверяет фильтры по знаку, сортировку и неизменность источника.
- Google Chrome / Playwright: 1824, 1672, 1440, 1280, 1150, 1024, 950, 821, 768, 640, 430, 390, 375, 320 px — без горизонтального переполнения страницы/модалки и текста кнопок. Проверены шесть вкладок и отсутствие бокового резерва в трёх обновлённых вкладках.
- Заметки: пустой и пробельный ввод отключает сохранение; добавление, изменение через Ctrl+Enter с сохранением даты, отмена добавления/изменения/удаления, подтверждение удаления одной и последней записи, обновление счётчика, возврат фокуса, Enter и видимый focus, длинный текст на 320 px. Два исходных текста Иванова сохранены.
- Материалы: существующие статусы, открытие ссылки в отдельной вкладке с `noopener noreferrer` без ложной отметки просмотра учеником, отправка новой ссылки с комментарием, загрузка PDF, скачивание с исходным именем, отмена/подтверждение удаления одного файла и обновление счётчика. Внешний сайт перехвачен локальным ответом: проверялся URL и поведение браузера, не доступность YouTube.
- Оплаты: три фильтра (4/1/3 операции Иванова), запись 3000 ₽ через прежнюю форму с появлением операции и изменением баланса, нулевой баланс/долг/предоплата, правильная сумма по умолчанию для долга Петрова, остаток абонемента Смирновой. Пустые состояния всех трёх вкладок проверены на Соколове. Ошибок JavaScript и загрузки ресурсов нет. Safari/WebKit не проверялся.
- Сравнение остальных вкладок до/после на 1672 и 390 px: «Уроки» и «Задания» совпали побайтно. В «Обзоре» различаются только 102 пикселя blur активной вкладки (до 16 уровней канала) на desktop и один пиксель на mobile (до 2); контент визуально прежний. JSX шапки/навигации и файлы остальных вкладок не менялись; файлы вне границ задачи сверены по SHA-256 перед переносом.
