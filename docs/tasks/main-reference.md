# Главная по референсу

- Статус: готово к ревью. Исполнитель: агент текущей задачи. Ревьюер: второй участник, ревью предстоит.
- Ветка: `feat/main-reference`; отдельный worktree `.worktrees/main-reference`. Основа — текущий `feat/dev-sync`, потомок dev, с копией локальных изменений пользователя; исходная рабочая папка не меняется.
- Границы: только главная и её контекст оболочки. Правила MAIN-1…3. Существующие шрифты и более свободный текст имеют приоритет над референсом.
- Общие файлы: оболочка/меню, тексты cabinet.ru.ts, токены, ADR web и stages. Исходные незакоммиченные изменения сохранены как базовое состояние, не относятся к этой задаче.
- Критерии: три показателя без долга; timeline и разделители без внешних карточек; действующие переходы, скрытие и отметки; честная API-сборка; адаптивность; скриншот 1648×960 и сравнение с референсом; lint/typecheck/tests/build.
- Вне объёма: новые API, смена шрифтов, сторонние ассеты, commit/push/merge/deploy.


## Проверки и передача

- MAIN-2: три новых теста сначала упали из-за отсутствия функции отбора, после реализации прошли. Всего frontend: 289 тестов, 45 файлов; lint, typecheck и build успешны (Node 22). У сборки прежнее предупреждение о чанке больше 500 kB.
- Chrome/Playwright: проверены отсутствие долга, три метрики, счётчик внимания 4 → 3 после скрытия, отметка прошедшего урока, открытие карточки, переходы в проверку и расписание по столбцу, мобильное меню. Ошибок JavaScript нет.
- Адаптивность: 1648, 1440, 1200, 1024, 768, 375 и 320 px; нет горизонтального переполнения страницы и изменённых блоков.
- Скриншот 1648×960 сопоставлен с исходным PNG. Сохранены текущий логотип, шрифты и данные; интервалы намеренно просторнее референса по поручению владельца. На телефоне кнопки выделенного урока вынесены под имя.
- `./scripts/dev.sh check` запущен и остановился при проверке ссылок: в исходных локальных правках удалён `UX-REVIEW.md`, на который ссылаются `docs/tasks/landing-ux.md` и `docs/adr/web.md`. Backend/Compose/полный e2e этим запуском не выполнены; удаление пользователя не отменялось.
- Рабочая API-версия сохраняет источник данных и обработчики, получила общие бескарточные секции и заголовок. Демонстрационные метрики не добавлялись в API-версию; интеграционный браузерный прогон API не выполнен.
- Остаются независимое ревью, устранение исходной битой ссылки и полный check до push/PR. Commit/push/merge не выполнялись; исходная рабочая папка не изменена.

После уточнения панели: lint, typecheck, 289 тестов и build прошли; Chrome — действия и ширины 320–1648 px без переполнения. Скриншоты обновлены.
