# Редизайн публичного лендинга

Исполнитель: текущий агент. Ревьюер: владелец проекта. Статус: готово к ревью.

Ветка: `style/landing-redesign`, отдельный worktree со снимком текущего состояния `feat/main-reference`. Источник: архив TutorFlow_Landing_Complete_Package.zip, ТЗ и PNG из него.

Правила: LANDING-11, LANDING-4…6, LANDING-9, SIGNUP-1…12. Область: публичная App, новые компоненты и изолированная тема лендинга, публичные WebP/SVG. Не менять кабинет, общие компоненты, auth/API, формы, роутинг и данные. Общие файлы: docs/adr/web.md, docs/stages.md и только добавление отдельного селектора темы в tokens.css.

Критерии: композиция по PNG; прозрачный маскот без обрезки; три карточки и полоса ИИ открывают доступные диалоги; тарифы берутся из siteConfig; работают вход/регистрация, демо, якоря, FAQ и юридические страницы. Неподтверждённые возможности не выдаются за работающие. Отзывы-примеры не публикуются. Все состояния FAQ изначально свёрнуты. Mobile 375/390/430 и desktop 1280/1440 без переполнения; reduced motion; скриншоты и визуальное сравнение. Кабинет до/после идентичен.

## Реализация

- Публичная композиция по PNG: hero с WebP-котиком, три короткие карточки, полоса ИИ, компактные тарифы и CTA. Ниже — демо, отзывы, исходная форма регистрации/входа, FAQ и юридические ссылки.
- Карточки, ИИ и тарифы открывают Radix-диалоги: клавиатура, Escape, удержание и возврат фокуса. FAQ изначально закрыт; есть мобильное меню и ссылка перехода к основному содержимому.
- Цены, лимит учеников и пробный период из siteConfig. Демонстрационные возможности обозначены. Без VITE_DEMO_URL в production посетителю показываются снимок кабинета и существующая регистрация вместо обещания гостевого демо. Этот сценарий сначала воспроизведён падающей браузерной проверкой, затем исправлен.
- Маскот и SVG из архива, без Three.js и новых зависимостей. Размеры иллюстраций заданы; главное изображение имеет высокий приоритет загрузки, остальные загружаются отложенно. Анимация отключена для prefers-reduced-motion.
- Новые переменные находятся только в селекторе data-landing-theme, включая порталы. Исходные глобальные токены не менялись; защищённые исходники кабинета, общего UI, авторизации и форм совпадают по SHA-256. Снимки шести страниц кабинета и обзора ученика до/после совпали побайтно с корректными локальными шрифтами.

## Проверки

- npm run lint, npm run typecheck, npm test, npm run build — успешно. 292 теста в 46 файлах. Прежнее предупреждение о JS-чанке более 500 kB остаётся.
- Chrome: все четыре диалога возможностей, focus trap/возврат фокуса, оба тарифа, FAQ, меню, якоря и юридические страницы; полная регистрация и вход на демоданных. Ошибок JS и загрузки ассетов нет.
- Размеры 1440, 1280, 1024, 768, 700, 430, 390, 375, 320 px: нет горизонтальной прокрутки, маскот и элементы управления целиком видны. Проверен reduced motion.
- Production: примеры отзывов скрыты, якорь отзывов сохранён с честным пустым состоянием; переходы без публичного демо ведут к снимку и регистрации. Реальные списания и серверная регистрация в рамках этого визуального прохода не выполнялись.
