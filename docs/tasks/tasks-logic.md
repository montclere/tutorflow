# Логика раздела «Задания» для обсуждения backend

Статус: готово к обсуждению. Исполнитель: текущий агент. Ревьюеры: владелец и напарник по backend. Ветка: docs/tasks-logic.

Результат: понятный документ с текущими возможностями демо, предложенной серверной логикой, сценариями, ограничениями и вопросами. Источник: TASKS-1…9 в web ADR и текущие модели tasks. Новые положения — предложения, не утверждённый API.

Границы: только документация и PDF для передачи; UI, API, данные и бизнес-логика приложения не меняются. Правила проекта: TASKS-1…9, ACL-1…10; новые серверные предложения — TASKS-SERVER-1…12. Общие файлы: docs/adr/README.md и docs/stages.md.

Критерии: различаются задача, работа, выдача и попытка; описаны задания/тренажёры, PDF, ИИ, роли, сохранение результатов и операции API. Чётко обозначены текущий статус и нерешённые вопросы. PDF проверен, Markdown-ссылки проверены. Нужна продуктовая и техническая сверка напарником.

## Передача

Подготовлен [исходник](../adr/tasks.md) и [PDF для напарника](../exports/tutorflow-tasks-business-logic.pdf). Описаны 12 областей: модель раздела, банк и черновик, форматы работ, выдача, прохождение, проверка и показ ответов, статусы, права, ИИ, PDF, серверные операции и сложные случаи. Все новые правила отмечены как предложения; точные HTTP-схемы не утверждались.

По просьбе владельца DOCX удалён; всё содержание сохранено в Markdown и экспортировано в PDF. PDF прочитан через PDFKit: 10 страниц, основной текст сверен с Markdown с нормализацией Unicode; первая и последняя страницы просмотрены. Проверены таблицы и основные разделы; служебные ID оставлены в исходнике Markdown. Локальные ссылки новых документов проверены. Общая проверка документации по-прежнему блокируется ссылками на ранее удалённый UX-REVIEW.md. Код не менялся, программные тесты не запускались.

Файлы: docs/adr/tasks.md, docs/exports/tutorflow-tasks-business-logic.pdf, текущая задача, указатель в docs/adr/README.md и статус в docs/stages.md. Результат перенесён в основной каталог после проверки исходных хешей. Commit/push не выполнялись. Следующий шаг — обсуждение открытых вопросов с напарником и подготовка отдельного API-контракта.
