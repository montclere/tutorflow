# Модальное окно теста по референсу

Статус: готово к ревью. Исполнитель: текущий агент; ревьюер: владелец/второй участник.

Источник: Tutor_Student_Test_Modal_Agent_Package.zip; правила STUDENT-TEST-MODAL-UI-1/2 и прежние TASKS-8 в ADR web.

Границы: TaskPlayer, опциональный вид AnswerInput, локальные test-modal стили/декор. Только work.kind=test; домашняя работа и отдельный TrainerPage сохраняются. Не меняются вопросы/банк, типы, хранилище, механика проверки/таймера/попыток/результатов, маршруты, backend, шапка/меню и другие страницы. Общие файлы: два компонента плеера, docs/adr/web.md, docs/stages.md.

Ветка style/student-test-modal-reference, .worktrees/student-test-modal-reference. Текущая демо-версия отсутствует в dev: отдельная ветка от HEAD со снимком незакоммиченных файлов, перенос явного списка с проверкой SHA-256. Чужие изменения сохраняются.

Приёмка: визуальная сверка desktop/tablet/mobile, состояния выбран/hover/focus/disabled, постоянные номера ответов, шаги/возврат/отметки, правильный и неверный ответ, результат/сохранение/повтор, контрольный тест/таймер, все прежние типы ответов, клавиатура и sticky footer без скролла страницы по горизонтали. Проверить, что вопросы/проверка не изменились; домашняя работа, отдельный тренажёр и соседние страницы совпадают с исходными снимками. Frontend lint/typecheck/test/build и общий check с честным результатом.

## Результат

Новый вид только для work.kind=test: цельная шапка, компактные связанные шаги и позиция вопроса, комфортная колонка до 1000 px с вопросом и вариантами, нижняя панель действий. Выбранный ответ сохраняет номер слева; справа отдельная отметка, состояние доступно через прежние checkbox/radio и aria-checked. Hover, selected, focus и disabled различаются; флаг дополнен aria-pressed. Существующий progressbar сохранён для скринридера, видимая позиция отражает текущий вопрос. На маленьком экране прокручивается вопрос; футер остаётся в пределах viewport. Результат теста получил согласованное оформление и внутренний скролл длинного разбора. Декор — небольшой отдельный WebP, скрытый на узком экране.

Банк, содержание, число задач, баллы, попытки, проверка, навигация, отметки и таймер не переписывались. Блоки finish/go/check/primary/stateOf и эффекты таймера дополнительно сравнены с исходником дословно. Appearance у AnswerInput опциональный; домашние работы и отдельный TrainerPage его не получают. Контрольный режим не раскрывает ответы раньше прежнего reveal; тренировка сохраняет мгновенную проверку. Нет новых API/моделей/зависимостей и искусственного loading синхронной проверки. Это прежняя демо-функциональность, не новый backend.

После закрытия теста фокус возвращается на вызвавший элемент. Когда он удалён или стал disabled после отправки, используется существующий main; исходное поведение домашней работы не меняется.

## Проверки

- Браузерный TDD: до кода выбор первого ответа убирал видимый номер «1»; тест это воспроизвёл, после изменения проверка зелёная. Отдельно тест контрольного режима воспроизвёл потерю фокуса при закрытии после исчерпания попыток; исправлен только возврат фокуса UI.
- Frontend: lint, typecheck, прежние 332 теста в 55 файлах и сборки demo/production успешны. Новых тестов формул ради стилей не добавлялось. Прежнее предупреждение о чанке >500 kB сохраняется.
- Chrome: четыре настоящих вопроса, disabled пустой проверки, выбор Space, постоянная нумерация/aria-checked/focus, отметка «Вернусь позже», переход/возврат с сохранением ответа. Правильный и неверный ответы, блокировка проверенного ввода, отправка Enter, итог 50%=2/4, реальное сохранение в library, чистая повторная попытка; X/Escape, возврат фокуса и 22 Tab внутри focus trap. В мобильном результате кнопка «Готово» дополнительно проверена через elementFromPoint во время уведомления об отправке и остаётся доступна.
- 18 размеров 1920×1080 / 1672×941 / 1600×900 / 1440×900 / 1280×800 / 1100×768 / 1024×768 / 900×720 / 821×900 / 820×900 / 768×700 / 600×720 / 430×844 / 390×844 / 380×740 / 360×640 / 320×640 / 320×568: нет горизонтального скролла ни диалога, ни страницы; основной CTA/feedback видимы после прокрутки вопроса. Визуально сверены desktop/laptop/tablet/mobile/320.
- Временный изолированный стенд через saveWork/assignWork: single, число, соответствия и текст дали 100%; контроль с пропусками — 25%, подтверждение пропусков, скрытые ключи до afterCheck и лимит одной попытки. Таймер 1 мин с Playwright clock создал ровно одну попытку, включая повторное продвижение времени. Длинный заголовок, 20 вопросов, варианты и разбор проверены на шести размерах вплоть до 320×568; кнопки доступны, разбор прокручивается. Тестовые работы не подменяют рабочие данные; исходники стенда удалены из worktree. JS/ресурсных ошибок нет. Safari/WebKit не проверялся.

Ещё четыре пары открытой домашней работы и активного отдельного тренажёра совпали побайтно. Оболочка и бизнес-модули сверены с исходным SHA-256 при переносе.
