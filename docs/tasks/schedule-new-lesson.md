# SCHEDULE-NEW-LESSON — новый урок и доводка расписания

- Статус: готово к ревью.
- Исполнитель: Claude. Ревьюер: владелец проекта.
- Ветка: текущая рабочая `codex/work-from-dev`; коммиты по шагам, без push.
- Результат: урок создаётся из одной панели со всех входов; карточка урока и виды расписания доведены по UX-ревью кабинета.
- ID правил: SCHEDULE-1…6.
- Файлы шага 1: `data/index.ts` (хранилище в памяти), `data/useSchedule.ts`, `model/newLesson.ts` (+ тесты), `pages/schedule/NewLessonSheet.tsx`, `FreeSlot.tsx`, `WeekView.tsx`, `ScheduleHeader.tsx`, `SchedulePage.tsx`, `schedule.module.css`, `pages/students/StudentSheet.tsx`, `mocks/types.ts`, `content/cabinet.ru.ts`.
- Вне объёма: сервер (уроки живут до перезагрузки), настройки репетитора (ссылка на встречу по умолчанию), цена урока в форме.

## Шаги

- [x] 1. Хранилище уроков в памяти, панель «Новый урок» со входами из «+ Урок», пустого места недели, свободного окна и карточки ученика; свободные окна видны всегда.
- [x] 2. Карточка урока: действия по времени урока, ссылка на карточку ученика (SCHEDULE-5).
- [x] 3. Вид «День» без дублирующих вкладок, имена в месяце, время в строке урока, компактная шапка на телефоне (SCHEDULE-6).

## Передача

- Проверки: ESLint, `tsc -b`, Vitest, сборка, `scripts/check.py`; сценарии проверены в браузере на 1440px и 375px (создание урока, повтор, пересечения, вход из карточки ученика, действия карточки урока, мобильные фильтры).
- Ограничения: уроки и отметки живут до перезагрузки; «Перенести», «Отменить», «Проведён» пока заглушки; список учеников не пересчитывает «следующий урок» после создания.
