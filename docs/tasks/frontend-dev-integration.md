## Передача

Текущая ветка интерфейса уже включает всю историю `origin/dev`; дополнительные серверные изменения не требуются. До очистки проверены Git bundle всех ссылок и архив содержимого 25 рабочих каталогов; резервные копии находятся в игнорируемой `.local-stack/cleanup-backup-2026-11-23/` и не публикуются.

### Проверки интеграции

- Frontend: ESLint, TypeScript, 332 теста в 55 файлах, рабочая и демо-сборки — успешно.
- Backend: Ruff, форматирование 67 файлов, Pyright (0 ошибок), 65 тестов pytest на изолированной PostgreSQL — успешно; серверные исходники не менялись.
- Два сценария Playwright в системном Chrome через настоящий Caddy 2.11.8 (CSP проекта), backend и PostgreSQL — успешно: регистрация, приглашения, ученик/родитель, вход, чужая карточка, урок (создать/отменить/восстановить), отзыв доступа. Подменена только доставка кодов локальным тестовым приёмником. Дополнительно проверены заглушки финансов, заданий и проверки в рабочей сборке.
- Демо: 12 маршрутов на ширинах 1440 и 390 px — без ошибок JavaScript и горизонтального переполнения.
- `python3 scripts/check.py`, `git diff --check` — успешно. Историческая блокировка ссылками UX устранена; обзоры сохранены в `docs/archive/`.
- `./scripts/dev.sh check` запущен, но останавливается на `docker: command not found`. Docker Compose и SMTP/Mailpit этим запуском не проверены; Caddy проверен отдельно нативным бинарным файлом той же версии, нативная проверка не объявляется полной проверкой стека.
- Регрессия ресурсов: новый тест сначала упал на `text/html` вместо SVG в исходной конфигурации Caddy; после замены безусловного rewrite на `try_files {path} /index.html` прошёл. Прямые SPA-маршруты и API сохранены.
- Перед слиянием: выполнить общую проверку в окружении с Docker и получить ревью второго участника. Ветка PR сохраняется до слияния; `main` не меняется.
