# Панель урока по референсу

- Статус: готово к ревью. Исполнитель: агент текущей задачи; ревьюер — второй участник, предстоит.
- Подготовка: ветка `style/lesson-panel`, отдельный worktree с копией текущего `feat/main-reference`. Перенос в основную папку только своих файлов после проверки исходного состояния.
- Область: правая панель урока в демо и рабочей сборке, общие детали её оформления. Правило LESSON-UI-1. По ответу владельца журнал учеников не входит в этот проход.
- Общие файлы: sheet.tsx (опциональный класс overlay), cabinet.ru.ts, tokens.css, ADR web, stages. API/схемы БД не меняются.
- Критерии: светлая панель 480–560px, скролл содержимого и закреплённые действия; баланс один раз, отсутствие «Проведено» и «Длительность»; статусы и действующие формы; длинный текст и мобильный экран; Escape/overlay/X и возврат фокуса; lint/typecheck/tests/build; сравнение скриншота с PNG.
- Ограничение: API материалов урока отсутствует. Пустое состояние и недоступная кнопка явно сообщают об этом; файлы из карточки ученика не выдаются за материалы выбранного урока.


## Передача

- Изменены LessonSheet.tsx, live/LiveLessonSheet.tsx; добавлены LessonDetails.tsx и lesson-details.module.css. Общие дата/время, переход к ученику, строки содержания, граница подключения материалов и восстановление фокуса. Ширина 540px на desktop и весь экран на телефоне; скролл отдельно от footer.
- В live/LessonPanels.tsx состояние открытой формы поднято в родительскую панель для кнопки переноса в footer; сами API-операции сохранены. Поля переноса адаптированы к узкому экрану. В sheet.tsx добавлен необязательный класс overlay, остальные панели сохраняют свои стили.
- Баланс демо берётся из модели ученика, показан один раз. Ноль не помечается оплатой. Сведения прошлого урока и заметка ученика подписаны по источнику: в демо нет отдельной модели содержания урока. В API-панели используются title/description/preparation/privateNote выбранного lessonId; баланс, платёжный статус и ДЗ не подставляются из демо.
- API файлов, списка материалов урока и ссылки видеовстречи нет. «Добавить» недоступна с пояснением; компонент принимает lessonId и необязательный обработчик подключения. Выбор файла и успешная загрузка не имитируются. «Войти» недоступна без ссылки. Демо-перенос/отмена/отметка сохраняют прежние уведомления «скоро»; реальная версия использует прежние API-формы.
