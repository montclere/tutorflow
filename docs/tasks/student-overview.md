Исполнитель: текущий агент. Ревьюер: владелец проекта. Статус: готово к ревью.

Правила: STUDENT-OVERVIEW-1, STUDENTS-13. Ветка: `style/student-overview`; снимок текущих несохранённых правок `feat/main-reference` в отдельном worktree.

Границы: содержимое обзора, сокращение подписи под именем и декоративная иконка. Четыре карточки; прочие вкладки, действия, API, данные и маршруты сохранены. Существующие формулы журнала переносятся в model без изменения для повторного использования.

Общие файлы: `docs/adr/web.md`, `docs/stages.md`, кабинетные тексты. Не менять другие накопленные правки.

Критерии: desktop близок PNG; адаптивная сетка; период работает; нет фиктивных контактов и метрик; ближайший урок открывается существующей панелью; действия и вкладки доступны с клавиатуры. Проверки lint/typecheck/test/build и браузер, скриншоты desktop/mobile.

## Результат и проверка

Реализованы четыре карточки, тихий холодный фон, SVG-кольцо, сокращённая шапка и водяной знак Lucide. В обзоре нет повторной боковой сводки; остальные вкладки и действия сохранены. Цель форматируется в шапке без изменения значения в данных. Формулы посещаемости и среднего ДЗ вынесены из журнала в модель без изменения; журнал сохраняет прежние экспорты.

Референс использован для компоновки, а данные взяты из текущей модели: у Иванова готовность 61%, посещаемость 100%, среднее ДЗ 65%; динамики недостаточно. Телефона ученика и адресов Telegram модель не содержит: телефон обозначен отсутствующим, доступен звонок родителю; значок мессенджера показывает существующий статус подключения, а не фиктивную ссылку. Динамика выражена в процентных пунктах по прежней формуле.

- `npm run lint`, `npm run typecheck`, `npm test`, `npm run build` — успешно; 292 теста в 46 файлах. До реализации периодов тест не проходил из-за отсутствующего модуля. Сборка сохраняет прежнее предупреждение о размере JS-чанка.
- Chrome: шесть вкладок, четыре верхних действия, меню, ближайший урок, периоды, долг и заканчивающийся пакет, отсутствие показателей, возврат фокуса. Размеры 1672/1658/1440/1280/1100/1024/768/600/390/320 px — карточки без переполнения, ошибок JS нет.
- Скриншоты: [desktop](../ui/student-overview-desktop.png), [mobile](../ui/student-overview-mobile.png), [mobile, нижние карточки](../ui/student-overview-mobile-bottom.png). Сравнены с PNG: исправлены высота карточек, отступы, заголовки, положение декора и мобильная сетка.
- `./scripts/dev.sh check` остановлен проверкой документации: существующие ссылки на ранее удалённый владельцем `UX-REVIEW.md`. Полная интеграционная проверка не выполнена.

Проверенный результат перенесён в текущий рабочий каталог `feat/main-reference` после сверки исходных хешей; сторонние изменения сохранены. Commit/push не выполнялись. Ревью владельцем и полная общая проверка после решения вопроса с документацией остаются открыты.
