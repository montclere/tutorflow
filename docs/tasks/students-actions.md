# STUDENTS-ACTIONS — рабочий раздел «Ученики»

- Статус: готово к ревью.
- Исполнитель: Claude. Ревьюер: владелец проекта.
- Ветка: текущая рабочая `codex/work-from-dev`; коммиты по шагам, без push.
- Результат: в таблице только главное; ученика можно добавить и пригласить; карточка ученика рабочая.
- ID правил: STUDENTS-1…6.
- Вне объёма: сервер (данные живут до перезагрузки, ссылка-приглашение — заготовка), «+ Задание» (сделаем с разделом «Задания»), подключение Telegram.

## Шаги

- [x] 1. Хранилище учеников в памяти; таблица из трёх колонок (ученик, следующий урок, баланс), метка «ждём подключения», пометка о заканчивающемся пакете; окно «Новый ученик» со ссылкой-приглашением и «Поставить первый урок».
- [x] 2. Карточка: оплата (по умолчанию — сумма долга), пауза / архив / вернуть / удалить с подтверждением, кликабельная история уроков, заметки, «Назначить расписание», «не подключён · скопировать ссылку».

## Передача

- Проверки: ESLint, `tsc -b`, Vitest, сборка, `scripts/check.py`; в браузере на 1440px и 375px — добавление ученика, ссылка, первый урок, оплата и пересчёт баланса, пауза и удаление (настоящими кликами мыши), открытие урока из истории, заметка, «Назначить расписание».
- Ограничения: данные живут до перезагрузки; ссылка-приглашение не открывает рабочую страницу; задания в обзоре и финансах по-прежнему из тестовых данных и не знают об удалённых учениках.
