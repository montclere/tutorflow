# Контуры карточек и вкладки учеников

- Статус: готово к ревью; исполнитель — агент текущей задачи, ревьюер — второй участник.
- Объём: оформление вкладок статуса учеников, показателей обзора/финансов и внутренних блоков карточки урока; по уточнению владельца — спокойный фон ближайшего урока в обзоре. Поведение и данные не меняются.
- Правило: VIBE-18. Критерии: различимые границы на светлом фоне, отдельные счётчики статусов, видимый фокус, сохранение мобильной компоновки.
- Ветка: `style/cabinet-outlines`, от текущего `feat/dev-sync`, содержащего `origin/dev`: новые компоненты отсутствуют в старой dev. Изолированная подготовка с переносом только своих файлов в текущую рабочую папку.
- Общие файлы: `styles/tokens.css`, `ui/Tabs.tsx`, `ui/StatTile.tsx`, ADR web и stages. Незакоммиченные изменения карточки ученика и её текстов не затрагиваются.
- Проверки: lint, typecheck, 286 тестов (45 файлов), build — успешно на Node 22. Сборка предупреждает о JS-чанке больше 500 kB. Chrome: визуально проверены вкладки, финансы, обзор и карточка урока; переключение статусов работает. На 375 px переполнения страниц нет; на 320 px изменённые блоки помещаются, но существующая шапка аккаунта выходит за экран (вне этой задачи). Ошибок JavaScript нет. Полный `dev.sh check` не запускался: backend/API не менялись, push/PR не выполнялись. Независимое ревью предстоит.
