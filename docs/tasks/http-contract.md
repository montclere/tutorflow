# Публичные HTTP-ответы

Границы: коды, Problem Details, заголовки и OpenAPI текущих Identity, Students и Health. Соседние модули, схема БД и правила доступа за пределами задачи. Правила INF-6/6.1/6.2, IDN-6/7/16/19, INV-10, ACL-3/6. Общие файлы: реестр ошибок, ASGI, маршруты, frontend API, ADR и договор API. Готовность: негативные сценарии в API/браузере, полное локальное `check`, коммит вместе с тестами и документами.
