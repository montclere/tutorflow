# tasks

Задачи для двух участников.

- Основной вариант — GitHub Issues с шаблоном «Задача»; до подключения GitHub копировать [template](template.md) в `<id>-<краткое-имя>.md`.
- Не вести одну задачу одновременно в Issue и локальном файле; в stages оставлять ссылку.
- Один исполнитель, второй участник — ревьюер. Статусы: todo, in-progress, review, done, blocked.
- Общий порядок: [workflow](../workflow.md).
