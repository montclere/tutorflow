# Финансы по референсу

Исполнитель: текущий агент. Ревьюер: владелец проекта. Статус: готово к ревью.

Ветка: `style/finance-reference`, отдельный worktree со снимком текущего `feat/main-reference`. Актуальный frontend и правки других разделов ещё не интегрированы в `dev`; они сохраняются как основа, а не заменяются старой версией.

Источник: задание владельца и `TutorFlow_Finance_Reference.png`. Правило FINANCE-UI-1 уточняет только представление FINANCE-1…4. Область: компоненты и CSS финансов, локальная модель отображения с тестами. Общие файлы: `docs/adr/web.md`, `docs/stages.md`, только тексты финансов в `frontend/src/cabinet/content/cabinet.ru.ts`, добавленные токены финансов в `frontend/src/styles/tokens.css`, привязка изолированной темы финансов в `CabinetShell.tsx` и её правила в `layout.module.css`. Остальные разделы, лендинг, API, данные и расчёты не меняются.

Критерии:

- Три KPI, две средние карточки, одна облегчённая таблица операций; заголовок «Финансы», месяц из состояния.
- Сохранены смена месяца, график, поиск/фильтры/раскрытие операций и запись оплаты. Внимание показывает до трёх строк, остальные доступны в диалоге.
- Числа берутся из существующей модели. Прогноз по урокам не называется выставленными платежами или недельными событиями. Напоминание и продление остаются исходными демонстрационными отметками, без обещания отправки или реального продления.
- В финансах используется оболочка главной, её разделитель непрерывен по одной переменной ширины; другие страницы не получают новых стилей.
- Проверены desktop около 1600 px, планшет, телефон, клавиатура, состояния без данных и основные действия. Есть снимки, результаты frontend-проверок и общей команды.

## Передача

- Три KPI в одну строку, компактный график и внимание в двух колонках, четыре колонки операций. На телефоне блоки идут последовательно, таблица прокручивается в собственной области с клавиатуры. Иконки — существующий `lucide-react`, поверхности — компоненты kit; новых зависимостей нет.
- Все суммы и формулы сохранены. На исходных данных: 82 400 ₽ получено, 28 800 ₽ ожидается, 1 200 ₽ долга, средний месяц 67 478 ₽, 54 урока, средний чек 1 962 ₽. Третья строка внимания честно показывает **21 предстоящий поурочный урок за ноябрь**, а не выдуманные 3 платежа на неделю; действие открывает расписание выбранного месяца.
- Прежние отметки напоминания/продления сохраняются в памяти демо; уведомления прямо говорят, что отправки сообщения и изменения абонемента нет. Полный список, сведения о плательщике и массовое действие доступны в диалоге. Запись оплаты использует прежнюю форму и обработчик. Экспорт остался исходным действием с уведомлением «скоро будет».
- `npm run lint`, `npm run typecheck`, `npm test` — успешно: 296 тестов в 47 файлах. Четыре новых теста FINANCE-UI-1 проверяют пустой список, приоритет и полноту событий, отсутствие выдуманных платежей и сохранение исходных данных. До реализации три теста падали по отсутствующему поведению, затем стали зелёными.
- Обычная production-сборка и демо-сборка Vite успешны. Сохраняется исходное предупреждение о JS-чанке больше 500 kB.
- Playwright / Google Chrome: 1600, 1440, 1280, 1180, 1024, 960, 821, 820, 768, 430, 390, 375, 320 px — нет горизонтальной прокрутки страницы и выхода карточек за экран. На desktop измерением подтверждены единая линия границы и одинаковая высота границы в шапке. На телефоне проверена клавиатурная прокрутка таблицы.
- Проверены фильтры, поиск и пустой результат, раскрытие 4 → 18 → 4 операций, месяц через стрелки/селектор/график, пустой журнал июня, меню, обе демонстрационные отметки, полный список внимания, массовое действие, клавиатура, focus trap и оплата из полного списка без двух одновременных диалогов.
- В демо записана тестовая оплата долга 1 200 ₽: получено стало 83 600 ₽, появилась 19-я операция, долг исчез из внимания. Проверен выбор ученика через «+ Оплата». Запись была только в памяти локального браузера, без API и реальных платежей. Ошибок JavaScript и загрузки ресурсов нет; reduced motion включён при проверках. Safari/WebKit не проверялся.
- 12 пар снимков до/после для лендинга, главной, расписания, учеников, заданий и проверки на 1600 и 390 px совпали побайтно. SHA-256 подтвердил неизменность данных, расчётов, API, авторизации, общих компонентов и лендинга; остальные страницы не редактировались.
- `./scripts/dev.sh check` останавливается на прежних ссылках в `docs/tasks/landing-ux.md` и `docs/adr/web.md` на удалённый `UX-REVIEW.md`. Общая интеграционная проверка не завершена; чужое удаление сохранено.
