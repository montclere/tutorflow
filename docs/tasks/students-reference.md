# Ученики по референсу

- Статус: готово к ревью. Исполнитель: агент текущей задачи; ревьюер — второй участник, предстоит.
- Правило: STUDENTS-UI-1. Ветка подготовки: `style/students-reference`, отдельный worktree с копией текущей локальной `feat/main-reference`, содержащей dev. Исходные изменения сохранены.
- Область: заголовок, controls, поверхность журнала, закреплённые колонки, даты, статусы, легенда и адаптивность. Сайдбар использует существующие общие стили NAV-1. Без смены бизнес-логики, данных, API и маршрутов.
- Файлы: StudentsPage, StudentsJournal, LiveStudentsPage, новые общие заголовок/стили учеников. Общие точки: CabinetShell, layout.module.css, tokens.css, ADR web и stages.
- Критерии: сравнение desktop со Students PNG; фильтры, табы, сортировка, периоды, виды и открытие ученика; внутренний горизонтальный скролл и фиксированные левые колонки; нет горизонтального скролла всей страницы; lint/typecheck/test/build.
- Рабочая API-версия сохраняет реальный список и приглашения: журнала, баланса, паузы и ДЗ в API пока нет, демонстрационные данные в неё не добавляются.


## Передача

- Изменены StudentsPage.tsx и StudentsJournal.tsx; добавлены StudentsHeading.tsx и students.module.css. Общий заголовок подключён в live/LiveStudentsPage.tsx; реальные API-данные и приглашения сохранены. Оболочка учеников использует общую шапку/сайдбар без верхней полосы и без синей рамки активного пункта.
- Журнал: белая поверхность, строки около 64px, крупнее ФИО/аватары/статусы, тонкие линии, выделенная сегодняшняя дата, закреплённые итоги и имя. На ширине 521–700px закреплено только имя, чтобы итоговые колонки не перекрывали всю историю. На телефоне сохраняются прежние карточки учеников.
- Посещаемость, среднее ДЗ, сортировка и выбор дат сверены с исходными функциями: код вычислений не менялся. Значения, статусы и события берутся из текущих данных. Пустая ячейка отображается тире.

- Успешны lint, typecheck, 289 тестов в 45 файлах и build на Node 22. Предупреждение сборки о JS-чанке более 500kB сохраняется.
- Chrome/Playwright: шесть исходных учеников и восемь дат; поиск, пустой поиск, фильтр должников (Дмитрий), пауза/архив/активные, журнал/список, 2 недели/месяц, сортировка по балансу и имени, открытие профиля с клавиатуры/закрытие/фокус, приглашение, закрепление имени при прокрутке. Проверены 1655, 1440, 1100, 768, 540, 375 и 320px: горизонтального переполнения страницы и ошибок JavaScript нет.
