# WEB-API — интерфейс на React поверх API

Перенос React-интерфейса в общую ветку и подключение его к API backend.

- Статус: в работе.
- Исполнитель: владелец интерфейса. Ревьюер: второй участник.
- Ветка / PR: `feat/web-cabinet` → dev.
- Результат: интерфейс на React ([INF-7](../adr/platform.md#inf-7--стек-веб-интерфейса)) работает с API по [контракту](../api/README.md); разделы без маршрутов API — на тестовых данных с пометкой «демо».
- ID правил: INF-7, WEB-1, WEB-2, правила [ADR интерфейса](../adr/web.md); модели — [identity](../adr/identity.md), [students](../adr/students.md), [lessons](../adr/lessons.md).
- Файлы и общие точки пересечения: `frontend/**`, `docs/adr/platform.md`, `docs/adr/web.md`, `docs/stages.md`. Backend, deploy и scripts не меняются.
- Зависимости от другой задачи: [занятия и расписание](lessons-schedule.md) — маршруты `/teacher/lessons`.
- Вне объёма: маршруты API для оплат, финансов, заданий, проверки и тренажёра; отправка приглашений из интерфейса в Telegram от имени сервиса.

## Шаги

- [x] 1. Слияние: React-интерфейс заменяет статический, правила перенесены в ADR, общий `check.sh` (линт, типы, Vitest, сборка, Playwright на стеке).
- [x] 2. Шрифты в сборке (CSP проверен на сборке с заголовками Caddy), общий клиент API с тестами, флаг демо-сборки `VITE_DEMO=1`.
- [x] 3. Регистрация, вход, восстановление пароля и включение кабинета по [identity](../api/identity.md); сессия кабинета, «Выйти», разделы без API — «скоро».
- [x] 4. Ученики: карточки, приглашения ученика и родителя, страницы принятия ссылок, архив по [students](../api/students.md); кабинеты ученика и родителя со списком карточек.
- [ ] 5. Занятия: календарь, разовые уроки и серии, отмена, посещаемость по [lessons](../api/lessons.md).
- [ ] 6. Браузерные сценарии Playwright под новый интерфейс.

## Критерии приёмки

- [ ] Сценарии регистрации, приглашения и расписания проходят на `./scripts/dev.sh check`.
- [ ] Рабочая сборка не показывает тестовые данные вне разделов с пометкой «демо».
- [ ] Получено ревью второго участника.
