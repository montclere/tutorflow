# Документация

- Цели продукта храни в `product.md`, пользовательские сценарии — в `use-cases.md`, точное поведение — в `business-rules.md`.
- Сохраняй ID UC и BR. Различай утверждённое правило и статус его реализации. Изменение правила согласуется отдельно от правки кода.
- Статус и порядок задач обновляй в `stages.md`, основные команды разработки — в корневом `README.md`. Из корня запускай `python3 scripts/check.py spec`.
