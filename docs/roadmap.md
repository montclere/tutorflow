# roadmap

Критерии запуска; техническое состояние — в [stages](stages.md).

- MVP: согласован сценарий, правила и объём; основной путь работает от UI до хранилища.
- Совместная разработка: два участника имеют доступ, dev защищена, PR проверяет второй человек.
- До выпуска: проверки приложения подключены и проходят локально и в CI, запуск воспроизводим, секреты вне Git.
- До эксплуатации: проверены права, журналы, резервная копия и восстановление, healthcheck и откат.
- Выпуск: отдельная команда владельца; инфраструктура пока отсутствует.
