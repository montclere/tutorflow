# Промпты для рабочих запусков Codex

## 1. Генерация очереди задач
Используй skill `plan-issues` для BR-001, BR-005 и BR-029 и минимальных обязательных зависимостей. Создай небольшие последовательные GitHub Issues с точными проверяемыми критериями и ссылками на BR-ID. Не реализуй код на этом этапе. Не создавай дополнительные документационные файлы.

## 2. Реализация следующей готовой задачи
Найди первый не заблокированный Issue в Ready, соблюдая зависимости. Применяй `implement-issue`: прочитай только связанные BR/UC и затронутый код; сформируй тесты и добавь привязку BR-ID; один RED, реализуй код, один адресный GREEN, один PR-check, один review. Сделай commit и открой PR с `Closes #N`. Не merge. По возможности не запускай full-suite локально — он запускается в CI.

## 3. Ревью открытого PR
Применяй `review-pr` к PR #N. Проверь связанные BR-ID, тесты, права доступа, регрессии и актуальные результаты CI. Если есть блокирующие проблемы — исправь их и проверь адресно. Если замечаний нет — сформулируй короткий итог. Не merge без моего разрешения.
