# skills

Процедуры из workflow форума, адаптированные к пустому TutorFlow. Входы для агента — `.agents/skills/*/SKILL.md`.

- [design](design.md) — правила и подход перед новой фичей.
- [new-module](new-module.md) — новый модуль backend.
- [tdd](tdd.md) — правила, тест, реализация.
- [migration](migration.md) — схема БД и данные.
- [add-dependency](add-dependency.md) — выбор и обновление зависимости.
- [docs-update](docs-update.md) — куда писать информацию.
- [release](release.md) — выпуск по поручению владельца.
- [console-tools](console-tools.md) — операторские команды.
- [landing-ops](landing-ops.md), [server-ops](server-ops.md) — заглушки эксплуатации до появления инфраструктуры.
