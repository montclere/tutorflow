# add-dependency

Когда: добавление или обновление библиотеки и инструмента.

1. Проверь, не решают ли задачу стандартная библиотека или текущие зависимости.
2. Для существенной новой зависимости сравни альтернативы по поддержке, совместимости, лицензии и стоимости.
3. Проверь актуальную версию и документацию; не выбирай версию по памяти.
4. Используй пакетный менеджер выбранного стека; обнови манифест и lock-файл вместе.
5. Для платного сервиса либо ограничительной лицензии проверь наличие разрешения владельца.
6. Выполни проверки приложения; существенный выбор и альтернативы запиши в decisions.

Пакетные менеджеры и стек пока не выбраны.
