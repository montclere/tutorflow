# release

Когда: владелец поручил выпустить версию или выкатить. Сейчас приложение и инфраструктура отсутствуют.

1. Проверь объём dev, готовность задач, зелёный CI в PR в dev и результат локальной команды `./scripts/dev.sh check`; проверки приложения обязательны после его появления.
2. Подготовь конкретный состав выпуска, версию, переменные, миграции, проверку здоровья и откат.
3. По поручению создай PR dev → main; второй участник проверяет результат. Сохраняй историю веток merge-коммитом.
4. Создание тега, публикация и деплой — отдельные действия в пределах выданного поручения. После push в main GitHub Actions повторяет общие проверки; публикация и деплой автоматически не запускаются.
5. После выкатки проверь здоровье и основной сценарий; при отказе выполни подготовленный откат.
6. Верни изменения выпуска из main в dev merge-коммитом и обнови статус.

До первого выпуска заполнить команды сборки, публикации, миграций, запуска и отката в `deploy/README.md`; рабочих команд пока нет.
