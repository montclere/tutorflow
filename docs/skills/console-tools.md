# console-tools

Когда: создание или запуск операторской команды. Команд приложения пока нет.

- Описывай назначение, окружение, аргументы и код возврата в `--help`.
- Для изменения данных указывай цель, объём, исполнителя и запись аудита; добавляй dry-run там, где он полезен.
- Проверяй окружение явно; тестовые данные не должны попадать в рабочую БД.
- До удаления данных подготовь резервирование и восстановление; выполняй только в рамках поручения.
- Не переносить команды, ключи и имена модулей форума в TutorFlow.
