# server-ops

Заглушка эксплуатации; рабочего сервера TutorFlow пока нет.

- До первого сервера заполнить deploy/README.md: доступы, окружения, выкатка, healthcheck, журналы, копии, восстановление и откат.
- Секреты хранить вне Git; проверять восстановление отдельно от рабочей среды.
- Не использовать адреса и скрипты форума; действия на сервере выполнять в рамках явного поручения.
