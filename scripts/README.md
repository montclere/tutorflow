# scripts

Общие команды для человека и агента; нужны Bash и Python 3.

- `./scripts/dev.sh check` — структура, ссылки Markdown, синтаксис shell и доступные проверки модулей.
- `./scripts/dev.sh help` — справка.
- Модульные проверки: `backend/scripts/check.sh`, `frontend/scripts/check.sh`, `deploy/scripts/check.sh`.
- Сейчас модули — заглушки: выводится SKIP. Сейчас проверяется каркас; появление кода или конфигурации модуля без его скрипта проверок считается ошибкой.
- GitHub Actions вызывает ту же команду на push в main и PR в dev; возможен ручной запуск.
- С первым кодом добавить установку зависимостей и сервисы в workflow; в скриптах модулей — линт, типы, тесты и сборку по выбранному стеку.
- Команд setup/up/release пока нет; добавлять с работающей реализацией.
