# Общие утилиты

- В этой папке живут команды, которые работают со всем репозиторием. Утилиты backend и deploy храни рядом с соответствующим модулем.
- Определяй пути относительно репозитория. Возвращай ненулевой код при ошибке и сохраняй подробные логи в `.artifacts/`.
- Используй массивы аргументов для запуска проверок. Основные команды проверки указаны в корневом `README.md`.
