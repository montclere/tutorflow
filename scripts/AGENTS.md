# scripts

Правила общих команд; действуют также [общие правила](../AGENTS.md).

- Запускай команды относительно корня репозитория, независимо от текущей папки.
- Завершайся ненулевым кодом при ошибке; неизвестная команда тоже ошибка.
- Не выполняй сеть, удаление данных, Git-публикацию или деплой из команды проверки.
- Подключай проверки модулей через `<папка>/scripts/check.sh`; выводи SKIP, пока модуль содержит только документацию; при появлении кода или конфигурации требуй скрипт проверок.
- Обновляй [README](README.md) при изменении команд.
